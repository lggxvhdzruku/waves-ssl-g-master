## Overview

Waves SSL G-Master Buss Compressor is an emulation of the legendary SSL G-Series console bus compressor, the go-to glue compressor for mixing pop, rock, and electronic music.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Waves SSL G-Master** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **SSL Circuit** | Accurate circuit modeling of the G-Series VCA compressor topology |
| **Glue Mode** | Program-dependent attack and release for natural mix cohesion |
| **THD Engage** | Optional harmonic distortion from the transformer circuit |
| **Stereo/Mono** | Full-stereo and dual-mono modes for mix bus and stem compression |
